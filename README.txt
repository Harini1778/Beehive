BeeCare Website — FIVEFORGE Design Thinking Project

FILES INCLUDED
- index.html — all website sections and project content
- style.css — complete styling, improved readable text, responsive layout and hero banner
- script.js — navigation, animations and back-to-top interaction
- images/ — your stakeholder visit photos from the project presentation

HOW TO OPEN IN VS CODE
1. Download and extract this ZIP file.
2. Open VS Code.
3. Select File > Open Folder.
4. Choose the extracted folder named BeeCare-Website-Final.
5. Open index.html.
6. If Live Server is installed, right-click index.html and select Open with Live Server.

IMPORTANT
- The hero banner uses an online bee-themed photograph, so internet access is needed to display it.
- The three stakeholder photos are included locally in the images folder and will display from the ZIP.
- The motorized brush is marked as the proposed solution. The other three are alternatives; final selection is pending faculty evaluation.
- Keep index.html, style.css, script.js and the images folder together in the same project folder.
